反馈需要哪些信息？ · Reporting a problem

请说明应用版本、Android 版本、出现问题的页面、复现步骤和预期结果。截图请先遮盖通知与个人信息。无需提供密码或完整学习数据库。

Include the app/Android version, affected screen, steps to reproduce and expected result. Redact notifications and personal information from screenshots. Never send passwords or your full study database.

购买与恢复 · Purchases and restore

参赛版本使用 RevenueCat Test Store，不产生真实扣款。Google Play 正式支付尚未上线。核心学习流程和全部本地历史免费，Pro 仅增加三个月和全部时段的模式比较。

若已测试购买但权益未显示，连接网络后在设置中尝试“恢复购买”。测试权益不代表真实商店订阅。正式商店购买、取消与退款仅在对应商店发布后适用。

The competition build uses RevenueCat Test Store with no real charges. Production billing is not live. The study loop and all local history remain free; Pro adds longer-range comparisons. If test access is missing, connect to the network and try Restore purchases in Settings. Test entitlements are not store subscriptions.

离线使用与 AI · Offline use and AI

任务缩小、专注、复盘和本地历史无需账户即可使用。本地伴侣规则建议可离线运行。当前参赛版本未配置远程网关。配置了网关的版本中，主动发送聊天消息或请求柯基微行动、复盘反馈可能发送相应文本与上下文；服务不可用时回退本地建议。统一同意机制尚未验证，远程 AI 保持关闭。

Task shrinking, focus, reflection and local history work without an account. Local companion suggestions work offline. The current competition build has no remote gateway configured. In a configured build, chat messages or Corgi micro-action/reflection requests may send text and context; unavailable service falls back to local suggestions. Remote AI remains disabled pending a verified consistent consent gate.

删除数据 · Delete data

在记录详情中删除单条记录，或通过 Android 设置清除应用存储以删除全部本地记录。此操作无法从 StudyLoop 云端恢复，因为应用不提供学习数据库云同步。系统备份按设备设置单独管理。清除数据或卸载不会取消未来的商店订阅。

Delete a record from Record Detail, or clear app storage in Android Settings. StudyLoop has no cloud sync for recovering the database. Manage Android backups separately. Clearing data or uninstalling does not cancel any future store subscription.

支持范围 · Support scope

可提交功能问题、错误反馈、权益问题和隐私请求。StudyLoop 不提供医疗或心理诊断服务；目前不承诺未经验证的邮件回复时限。

Support covers product questions, bugs, entitlements and privacy requests. StudyLoop does not provide medical or psychological diagnosis. No unverified email response-time guarantee is made.
